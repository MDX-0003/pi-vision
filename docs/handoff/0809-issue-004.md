## Bug 修复记录

### Bug 6: UE list_properties 返回 lowercase camelCase

**症状**: whitelist 使用 PascalCase（`LightColor`, `Intensity`），`list_properties` 返回 lowercase camelCase（`lightColor`, `intensity`）→ 匹配率 0%。

**修复**: whitelist 全部改为 lowercase camelCase。

### Bug 7: 组件键名因 actor 类型而异

**症状**: 假设 SkyLight 的组件键为 `skyLightComponent` → `get_properties` 返回空。
实际 UE 中 SkyLight 用 `lightComponent`，ExponentialHeightFog 用 `component`。

**修复**: `ATMOSPHERE_COMPONENT_GLOBS` 中显式列出每个 actor 类型的 `compKeys`(实测确认)。

### Bug 8: Actor 名截断

**症状**: `actorRefPath.split(":").pop()?.split(".")[0]` → `/Game/Main.Main:PersistentLevel.DirectionalLight_0` 被截断为 `PersistentLevel`。

**修复**: 只做一次 split → `actorRefPath.split(":").pop()` → `PersistentLevel.DirectionalLight_0`。

## 决策记录

### D11: whitelist 为主，Vision classify 为备

**决定**: 使用硬编码 whitelist（~35 个已知氛围属性）作为主方案。不主动调用 Vision 做属性分类。

**原因**: Python harness 历史表明属性分类不稳定。whitelist 在当前场景中覆盖率足够。

### D12: 属性名必须以 UE list_properties 实际返回为准

**决定**: 所有 whitelist 属性名必须与 `list_properties` 返回的 key 精确一致（lowercase camelCase）。不做大小写模糊匹配。

**原因**: `get_properties` 接受大小写变体但 `list_properties` 只返回一种格式 → 一致性风险。
