## 双重保障架构

| 层 | 机制 | 可靠性 |
|:--:|------|:--:|
| **代码层** | `tool_call` block + Phase 状态机 | 100% — LLM 无法绕过 |
| **文本层** | `before_agent_start` 注入 Phase/Tier 上下文 | 辅助 — 告诉 LLM 为什么被阻止 |

示例: LLM 试图跨 Tier 调 PostProcess:
```
LLM → set_properties(PostProcessVolume_0, whiteTemp, 6500)
  ↓
tool_call handler: currentTier=1, targetTier=3, tier1 major gap exists
  ↓
{ block: true, reason: "当前 Tier 1，禁止调 Tier 3 的参数..." }
  ↓
LLM 收到 block → system prompt 中有 Phase 说明 → 知道该调什么
```

## 决策记录

### D13: 工作流规则在事件层，工具保持纯函数

Phase/Tier/防呆/停止条件全部在 `tool_call` + `tool_result` + `before_agent_start` 事件 handler 中实现。
三个自研工具 (map_atmosphere/assess_lighting/check_dimension) 不感知 Phase 状态机——它们只负责输入→输出。
关注点分离：工具做计算，工作流做编排。
