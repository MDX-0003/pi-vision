## 与 Python Harness 的对比

| 维度 | Python Harness | Pi Extension |
|------|:---:|:---:|
| LLM 控制方式 | 提示词注入 + Skill 文本 (建议性) | tool_call block + Tier 门控 (强制性) |
| Vision 分析 | Interceptor post_call → 文本注入 | Pi 工具 (LLM 必须调用) |
| 工具注册 | 握手时获取 + 透传 | 握手时获取 + TypeBox schema 编译 |
| Session 管理 | 自建 JSONL | Pi 原生 SessionManager |
| 截图 | DWM CaptureEditorImage (不稳定) | GPU CaptureViewportImage (稳定) |
| 代码量 | ~5000 行 Python | ~3300 行 TypeScript |
| 测试覆盖 | 384+ Python tests | 94 项 TS 验证 (纯逻辑 + 端到端) |
