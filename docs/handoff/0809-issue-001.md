## 关键发现

### UE 工具集延迟加载

- `tools/list` 初始返回 3 个引导工具
- `list_toolsets` 返回纯文本格式——**不是 JSON**，需正则解析 `/^\s*-\s*(\S+):/gm`
- 逐个 `load_toolset` → 等待 500ms → re-list → 219 个工具

### 组件属性两步跳转

`LightColor` 不在 Actor 上，在组件上：
1. `get_properties(actorRefPath, ['directionalLightComponent'])` → 获取组件 refPath
2. `get_properties(componentRefPath, ['LightColor'])` → 获取实际属性值

### UE MCP 参数规范

```typescript
// get_properties: instance 是 refPath 对象
{ instance: { refPath: "/Game/.../ActorName.ComponentName" }, properties: ["LightColor"] }

// set_properties: values 是 JSON 字符串（不是裸 object）
{ instance: { refPath: "..." }, values: '{"LightColor":{"R":0.5,...}}' }

// find_actors: tag 是必填字段
{ glob: "*DirectionalLight*", tag: "" }
```

### CaptureViewportImage vs CaptureEditorImage

| 维度 | 旧 | 新 |
|------|----|----|
| 截图方式 | DWM swap chain | GPU RenderTarget → ReadPixels() |
| 窗口焦点 | 必须前台 | **不需要** |
| 返回格式 | base64 (~1-25 MB) | 文件路径 (~200 bytes) |
| 稳定性 | 间歇性失败 | 始终可用 |

## 决策记录

- **D1**: 使用 `@modelcontextprotocol/sdk`（非手写 JSON-RPC）
- **D2**: 组件属性发现在 `map_atmosphere` 工具内部透明处理
- **D3**: CaptureViewportImage 返回文件路径 → `fs.readFileSync` → base64 → Vision
- **D4**: 强制排除 `CaptureEditorImage`（PRD Issue 002 2.5）
